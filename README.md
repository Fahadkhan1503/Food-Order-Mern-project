# 🍽️ Restaurant Reservation System (MERN)

A full-stack restaurant reservation system built with the MERN stack. Customers can fill out a reservation form, and their details are stored in a MongoDB database.

**Live Demo:** [food-order-mern-project.vercel.app](https://food-order-mern-project.vercel.app)  


---

## ✨ Features

- 📱 Responsive restaurant landing page (Home, About, Menu, Team sections)
- 📝 Reservation form with fields for first name, last name, email, phone, date, and time
- ✅ Form validation (name length, valid email, 11-digit phone number)
- 📨 Reservation data sent to backend API and stored in MongoDB
- 🔔 Toast notifications for success/error feedback
- 🔄 Redirect to a success page after reservation

> **Note:** This is a reservation system only. No user login, no food ordering, no cart, and no payment processing.

## 🛠️ Tech Stack

### Frontend
- React 19
- Vite
- Axios
- React Router DOM
- React Hot Toast (notifications)
- React Icons
- React Scroll

### Backend
- Node.js
- Express 4
- MongoDB with Mongoose
- Validator (email validation)
- CORS
- Dotenv
